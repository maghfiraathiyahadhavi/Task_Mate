# TaskMate

TaskMate adalah aplikasi pengelola tugas sederhana berbasis React + Vite.

## Menjalankan project
1. Pastikan Node.js sudah terpasang.
2. Ekstrak ZIP project.
3. Buka folder project di VS Code.
4. Jalankan terminal pada folder project, lalu ketik:
   ```bash
   npm install
   npm run dev
   ```
5. Buka alamat localhost yang ditampilkan oleh Vite di terminal.

## Fitur
- Dashboard dengan ringkasan total tugas, tugas selesai, dan tugas belum selesai.
- Indikator progres penyelesaian tugas.
- Tambah, edit, hapus, dan tandai tugas selesai.
- Pencarian berdasarkan judul atau deskripsi.
- Filter status dan prioritas.
- Pengurutan tugas berdasarkan terbaru, abjad, atau prioritas.
- Hapus seluruh tugas yang sudah selesai.
- Penyimpanan data menggunakan localStorage browser.

## Catatan
Project ini hanya menggunakan sisi frontend. Tidak ada database, API, atau backend. Data tugas disimpan secara lokal di browser melalui localStorage.
